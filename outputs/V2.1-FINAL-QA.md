# v2.1 최종 QA

## 1. 수정된 파일

- `js/projects.js`: 이미지 src가 빈 문자열 또는 공백이면 이미지 요소를 만들지 않도록 보완.
- `README.md`: v2.1 기록, 최신 검수 문서, 데이터 ID와 사진 폴더 매핑 정리.
- `assets/images/projects/research/.gitkeep`, `assets/images/projects/community-project/.gitkeep`: 요청한 사진 폴더 추가. 나머지 요청 폴더와 기존 폴더는 보존.
- `outputs/site/`, `outputs/portfolio-github-pages.zip`: 최신 배포본 갱신.

## 2. 해결한 오류

- 이미지 경로가 비어 있어도 현재 페이지 URL로 해석되어 불필요한 이미지 요소가 생성될 수 있던 조건을 차단했습니다. 카드·제목·상세·지표는 이미지 검증과 분리되어 있습니다.
- 요청 폴더명과 기존 프로젝트 ID의 차이를 문서화했습니다. `research-data-analysis` ID는 `research/`, `community-welfare` ID는 `community-project/` 파일을 참조할 수 있습니다. 기존 경로도 유효합니다.
- 375·430·768·1024·1440px에서 주요 카드 4개·추가 경험 4개와 이미지 없는 텍스트 상세가 정상 표시되었습니다.
- 검수용 이미지 객체로 대표 사진 1개·갤러리 5개를 연결해 모달 표시와 alt를 확인했습니다. 실제 데이터는 이미지 없는 상태로 유지합니다. 외부 사진을 추가하지 않았습니다.
- GitHub Pages 형태의 `/portfolio/` 경로에서 리소스 요청, 주요 메뉴·활성 상태, 내부 링크·고유 ID·제목 단계, 키보드 초점, 모달 닫기·초점 복귀·스크롤 잠금, 가로 넘침을 확인했습니다. 검수 범위의 정상 요청 실패와 스크립트 오류는 없었습니다.

## 3. 콘텐츠 변경사항

이번 검수에서 새 자기소개·경력은 추가하지 않았습니다. 기존 v2.1 보정 사항이 다음과 같이 반영되어 있음을 확인했습니다.

- 졸업논문 제목·부제는 제공 원문이며 공식 영문 제목을 만들지 않았습니다. 개별 심층 인터뷰·반구조화 질문·일반적인 질적 분석 및 3개 구성요소를 표시합니다. 2명 대상 탐색적 연구임을 명시하고 미채택 분석방법명은 없습니다.
- KOICA는 My Contributions / 주요 수행 다음에 Team Communication Results / 팀 홍보 운영 성과를 배치합니다. 콘텐츠 60개, 조회 92,207, 방문 2,599, 팔로워 약 2배 이상은 팀 채널 성과로 명시됩니다.
- Sweden 강의명·설명은 유지하고 단독 SDGs 태그는 제거했습니다. About의 SDGs는 유지됩니다.
- Skills 내부는 한국어 우선이며 Claude Code와 Google Workspace는 없습니다. 질적 인터뷰 분석이 포함됩니다.
- Contact는 이메일과 mailto 링크만 있습니다. 현재 소스·배포 HTML에는 전화번호·tel 링크가 없습니다.
- 사업 총괄·M&E·Impact Evaluation·Budget Management 등을 보유 경력으로 표기하지 않습니다. 예산·모니터링·기관 내부 운영은 학습 관심 영역에 배치합니다.

## 4. 아직 이미지가 필요한 프로젝트

모든 8개 경험의 사진은 미등록 상태입니다. 사진은 선택 사항이며 없어도 내용이 표시됩니다.

| 경험 | 권장 폴더 (`assets/images/projects/` 아래) | 제공 가능한 자료 예시 |
|---|---|---|
| KOICA 프로젝트 봉사단 | koica-paraguay/ | 캠페인·사진전·홍보물·채널 통계 |
| 복지관 하계실습 | welfare-practicum/ | 캠페인·프로그램 활동·계획서 |
| 정량 연구 | research/ | 설문·SPSS 분석·발표 자료 |
| 졸업논문 | thesis/ | 논문 표지·연구 과정·선정 확인 자료 |
| 지역사회복지론 팀 프로젝트 | community-project/ | 관찰·활동 결과 자료 |
| 학생회 | student-council/ | 프로그램·봉사활동 자료 |
| 의료사회사업연구학회 | medical-social-welfare/ | 학술제·학회 활동 자료 |
| 공연장 현장 운영 | field-service-operations/ | 공개 가능한 현장 운영 자료 |

사진 파일을 넣고 해당 프로젝트의 `heroImage` 또는 `images`에 `{src, alt, caption}`을 등록하면 자동 배치됩니다. caption은 선택, alt는 필수입니다. src는 `assets/images/projects/research/example.webp`처럼 실제 파일 경로를 입력합니다. 파일명은 예시이며 실제 파일을 생성하지 않았습니다. 폴더 자체를 자동 검색하지는 않습니다.

## 5. 사용자가 추가로 확인해야 하는 부분

- 실제 사진·자료의 선택, 설명과 공개 가능 여부. 식별 가능한 상담·참여자 자료는 필요한 부분을 가려 주세요.
- 팀 홍보 수치의 집계 기간·팔로워 비교 기준·근거 자료.
- 30초 검토: 첫 화면과 초기 스크롤에서 전공, 봉사단·복지관 경험, 운영·기록·커뮤니케이션 및 기여·학습 방향이 드러납니다. 다만 정량·질적 연구의 상세한 구분은 주요 프로젝트와 Skills에서 더 명확해지므로, 모바일의 짧은 훑어보기만으로 모두 전달된다고 단정할 수 없습니다. 제공된 Hero·자기소개는 임의 변경하지 않았습니다. 실제 채용담당자를 대상으로 시간을 측정한 검증은 아닙니다.
- 실제 GitHub Pages 공개 URL과 모바일 기기·스크린리더에서 최종 확인이 필요합니다. 이번 검수는 로컬 Edge 환경이며 실제 배포 또는 v2.1 Lighthouse 측정은 하지 않았습니다.
- 이전 QA 보고서의 전화번호·논문 TBD 설명은 과거 기록입니다. 현재 상태는 이 문서를 기준으로 확인합니다.
